Welcome

MC-909 Editor is a plugin that talks to your MC-909 over MIDI and shows every sound parameter as a knob, dropdown or envelope you can reach with a mouse. Turn something and you hear it on the unit straight away.

What you can edit

Patch tones, LFOs, envelopes, filters, the tone mix table, rhythm kit pads, effects, reverb, compressor, part settings and system settings.

How it talks

The plugin opens its own MIDI ports and sends Roland SysEx directly. It does not use Ableton's MIDI routing for this, so the same plugin behaves the same in any host.

What you need

A Windows PC, Ableton Live with VST3 support, an MC-909, and a MIDI link to it (DIN MIDI through an interface such as the UM-1, or the unit's USB).

Good to knowEdits go to the unit's temporary edit buffer. They are real and audible, but they are lost when you reselect the patch or kit on the MC-909. Store a sound you like with the WRITE button on the unit. The limits section explains why the plugin can't press WRITE for you.

This is an independent project. It is not made by or affiliated with Roland, and "Roland" and "MC-909" belong to Roland Corporation.

Install

The plugin is built by GitHub Actions in your own fork, so you never need a compiler.

  1. Upload the source. Drop the files from each zip into the Source/ folder of your repository using GitHub's web upload. Commit, and the build starts on its own.

  2. Wait for the green tick. Open the repository's Actions tab. A build is finished when its run shows a green check.

  3. Download the artifact. Open the run and download MC909-Editor-windows from the Artifacts list at the bottom. Unzip it.

    Chrome sometimes blocks this zip as "dangerous" because it holds an unsigned plugin. If there is no Keep button, turn Safe Browsing down to Standard for the download, or use Edge or Firefox.

  4. Close Ableton, then copy the plugin. Put MC-909 Editor.vst3 in C:\Program Files\Common Files\VST3\, replacing the old one. Live locks the file while it is open.

  5. Open Live and rescan. If it doesn't appear, go to Settings, Plug-ins, and press Rescan. Drag MC-909 Editor onto an audio track.

Why an audio trackThe plugin has no audio of its own. It sits in the audio effect list so it can stay open while the MC-909 makes the sound. Put it on a spare audio track and leave the track's monitoring off.

Connect

Two directions: the plugin sends to the unit, and the unit replies back.

  1. MIDI Out (top row, first box): choose the port that leads to the MC-909's MIDI IN. With a UM-1 this shows as UM-1.

  2. MIDI In (second box): choose the port that receives from the MC-909's MIDI OUT. Again UM-1 on the UM-1.

  3. Unit: leave it on Unit 1 unless you changed the unit's Device ID in System settings.

  4. Press Detect. The status text beside it should read 909 found Out ok In ok. RX counts replies received, with how many were stored.

  5. Press Get from MC-909. The plugin asks for the current part's patch, tones, effects, system settings, and the rhythm kit if that part holds one. The status shows Sending... while it works.

Port busy?Only one program can use a MIDI port at a time. If Out or In shows CLOSED, another program (or Live's own MIDI preferences) has the port. Turn its Track and Remote off for that port in Live, or close the other program.

Press Probe only when asked. It writes a diagnostic log of what the unit says back, which is what makes new pages possible. Holding Alt while clicking Get runs the same probe.

Controls

Five kinds of control cover the whole editor.

Knob

Drag up or down (left and right also work). Double-click to reset it to its minimum, or to zero for centred knobs. The number underneath is the value the unit shows.

Dropdown

Click, then choose. Used for types, modes and sources, such as filter type or Matrix Control source.

OFF / ON pill

One click toggles. The pill lights up when it is on.

Number box

Drag sideways or vertically to change it. Hold Shift for single steps. Double-click and type an exact value, then press Return. Used for wave numbers, key ranges and effect parameters.

Envelope

Drag the dots. Horizontal movement is time, vertical is level. Hover a dot to read its value. Pitch and filter envelopes have five levels, amp has three with fixed ends.

Filter curve

A picture of the filter shape for the chosen type, cutoff and resonance. It is a sketch to read at a glance, not a measurement of the hardware.

ValuesWhere the hardware uses a centred scale, the editor shows it centred too: for example pan runs -64 to +63, and Coarse Tune shows semitones around zero.

Pages

Pick a tab to see what it holds. The tabs in this explorer match the ones in the plugin.

Help mode

Built-in info tiles. Turn Help on and hover any control to read what it does.

  1. Click Help, the button at the left of the bar above the keyboard. The page gets a coloured frame.

  2. Hover a knob, dropdown, toggle, number box, envelope dot or the filter curve. A tile shows its name, the values it accepts, and a plain-English description taken from Roland's Owner's Manual.

  3. Nothing is edited while Help is on: clicks are ignored. Click Help again to leave. Help and Teach knobs switch each other off.

Effect parameters On the FX page, each box is named after the effect you picked, for example Filter Cutoff for SUPER FILTER, and Help describes it. Names and ranges come from the Owner's Manual. Dropdown-type parameters (such as Filter Type) open a menu. Numeric ones show the unit's stored number, so for parameters with decimal ranges, such as Rate in Hz or times in ms, compare with the unit's own screen.

Rhythm kits

Drum parts are edited on the Rhythm page. It only has data when the selected part holds a rhythm kit, usually Part 10.

  1. Set Part to the rhythm part (Part 10 in a typical setup).

  2. Press Get from MC-909. All 16 pad names appear in the Pads card, with the kit name underneath.

  3. Click a pad button. The cards fill with that pad.

  4. Use TONE 1–4 in the header to choose which of the pad's four tone layers the Wave and Mix & Velocity cards show. The Pad – All Tones card, the filter and the three envelopes belong to the whole pad.

Pads

16 buttons, pads 1–8 on the left and 9–16 on the right.

Wave

Tone on/off, wave group, gain, group ID, wave numbers L and R, FXM.

Mix & Velocity

Coarse, fine, pan, level, velocity range and fade, random and alternate pan.

Pad – All Tones

Assign (multi or single), mute group, envelope mode, level, coarse, fine, random pitch, pan, reverb sends, bend range.

Which key plays which padPad 1 answers to key 59 (B3), pad 2 to key 60 (C4), and so on up to pad 16. Play the part's channel to audition them (see Playing notes).
Kit edits are temporaryThe unit reloads the kit when you reselect it, which discards edits. Press WRITE on the unit to keep them. Send to MC-909 does not send rhythm kits.

Playing notes

The keyboard at the bottom of the window plays the MC-909 directly, without going through Live.

  • Click a key to play it. The line above the keys tells you the MIDI channel, for example On-screen keys play on MIDI Ch. 10 (Part 10). The channel follows the Part box.
  • Pick the part first, then play. A drum part answers to its pad keys, a patch part to normal notes.
  • From your MPK or Push, Live must send MIDI to the MC-909 on a MIDI track: set the track's MIDI To to the unit's port and the channel to the part's channel. The plugin does not receive MIDI from Live.

Set up in Live

One audio track hosts the plugin, one MIDI track plays the MC-909, and one audio track brings its sound back. Set it up once, save it as a template.

1. Editor track

Create an audio track and drop MC-909 Editor on it. It is an audio-effect plugin that talks to the unit on its own MIDI ports, so this track carries no sound and can stay silent. Choose the unit's MIDI Out and MIDI In in the plugin header (for example the UM-1) and press Detect.

2. Play track

Create a MIDI track. Set MIDI To to the MIDI interface the MC-909 is on, and the channel to the part you want. Part 1 is channel 1, part 10 is channel 10. The plugin's Part box and the line above its keyboard tell you the number.

3. Return track

Create an audio track with Audio From set to the interface inputs the MC-909's outputs are plugged into (for example the UMC204HD). Set monitoring to In to hear the unit while you play, or Auto once you record it.

One program owns the MIDI portOn Windows a MIDI port can usually be opened by one program at a time. If the plugin shows Out CLOSED, Live's own MIDI preferences, another plugin instance or another app is probably holding that port. Close the other holder, then re-pick the port in the plugin header. Only keep the Track switch on in Live's MIDI preferences for ports you actually play through Live.

Why two tracks?

The editor plugin sends SysEx directly to the unit and cannot receive notes from Live. So Live plays notes through a normal MIDI track, and the plugin only edits sounds. Keep them on separate tracks and a stuck port on one never stops the other.

Part, channel and track map

The MC-909 has 16 parts, each on its own MIDI channel. A tidy template is one MIDI track per part you use, all sending to the same MIDI port, each on its own channel. The editor edits whichever part its Part box shows, so change the Part box to match the track you are working on.

Saving

The plugin's state, including your Teach assignments, is saved in the Live set. The sound edits themselves live in the unit's temporary memory. Store a sound you like with the unit's WRITE button. See what it can't do.

Teach knobs

Eight macro knobs. Teach each one a parameter from any page, then put the eight knobs on your MPK's K1 to K8.

Part 1: teach the slots

  1. Click Teach knobs in the bar above the keyboard. The page dims and the first slot lights up.

  2. Click any control: a knob, dropdown, toggle, number box, or an envelope dot. A tag shows Assign: Cutoff. The slot takes that parameter and the next slot is armed.

  3. Click slot cells directly to jump between slots. Double-click a slot to clear it. Clear all clears every slot.

  4. Click Done teaching when finished. Assignments are saved with your Live set.

Part 2: put them on the MPK in Live

The plugin cannot see Live's MIDI, so the eight knobs show up in Live as automation sliders called Knob 1 to Knob 8, and Live's own MIDI mapping connects them to the controller.

  1. Add the sliders to Live's device strip. Click Configure in the device title bar. Then move each little round dial in the teach bar once (dial in cell 1, then 2, and so on). Each appears in the strip. Click Configure again to leave.

  2. Clear old mappings. If K1 or K2 already controls one of the plugin's built-in sliders such as Cutoff, press Ctrl+M, click that slider, press Delete.

  3. Map. With map mode on, click Knob 1 in the strip, then turn K1 on the MPK. Repeat for Knobs 2 to 8. Press Ctrl+M again to leave.

  4. Play. Turn K1: the assigned parameter moves in the editor and on the unit.

Rules of the road A knob assigned to a per-tone parameter follows whichever TONE button is selected when you turn it, and whichever tones are ticked under AUTOMATE for the built-in sliders. A rhythm parameter follows the selected pad. Live shows the new names only after you close and reopen the plugin window.
MPK doing nothing?In Live's Settings, Link / Tempo / MIDI, make sure the MPK's input has Remote ticked.

Workflow tips

Habits that make the editor and the unit work well together in a session.

Start from a sound

Pick the patch on the unit first, press Get from MC-909, then edit. The editor shows the unit's current temporary patch, so you tweak something that already sounds right.

Check the status line

If values look wrong or nothing comes back, look at the status line first: both ports should say open. Then check the Unit (device ID) box and press Detect.

Edit by ear, store by hand

Edits are live. When you hear something good, press WRITE on the unit before changing patch or kit, because reselecting loses the temporary edits.

Teach for the session

Teach eight knobs for the sound you're building: Cutoff, Resonance, filter envelope depth, LFO rate, Amp Release, Reverb Send and so on. Map them to K1 to K8 and play it like a hardware synth.

Print to audio

Record the return track while you move knobs, then you have the performance as audio even though the unit's own state is temporary. Do this before moving on to a new sound.

Record the knob moves

Arm Live's automation (A) and move a mapped knob to record it as automation on the editor track. On playback the plugin sends the moves to the unit in time with the song.

Mind the channel

The editor edits the Part shown in its header, the MIDI track plays the channel it is set to. If a knob move changes nothing you hear, check both point at the same part, and that the right tone is ticked under AUTOMATE.

Keep latency in check

The MIDI interface adds a little delay to every note. Record the MIDI track, then nudge the clip or use Live's track delay so the return audio lines up with the grid. Edits from the plugin are not timing-critical for notes.

Let Help teach you

New parameter? Turn on Help and hover it. Roland's wording is in the tile, without leaving the plugin.

Quick routine Open Live, open the plugin, check the status line shows both ports open, pick the part, press Get from MC-909, tweak, teach knobs, play, WRITE the keepers on the unit.

What it can't do

Some limits are the MC-909's, some are choices made to keep your sounds safe.

Storing sounds

Roland's MIDI document lists only the temporary edit areas and has no write command. The user patch and user kit memories can't be reached by SysEx, so the plugin can't press WRITE. Press WRITE on the unit when you like a sound.

Effect names

Roland's MIDI document gives each MFX a type number and 32 raw parameters, but not what they mean per effect. The editor takes the names and ranges from the Owner's Manual (pp. 90 to 107), in the order printed there. Type 0 is treated as OFF and 1 to 47 follow the numbered list.

Send to MC-909

Send writes the editor's copy back, but only blocks you have read with Get. It never sends zeros for unread data and does not send rhythm kits. This path has seen less testing than Get and live edits, so try it first on a throwaway patch.

Display refresh

The unit's own screen may not redraw while you edit over MIDI. Judge by ear, or reselect the part on the unit.

Not every page is designed

Part, Comp/EQ, System, Master and All Tone are straight parameter lists. They work, they're just plain.

Host MIDI

The plugin doesn't take MIDI from Live. Play it with the on-screen keys, or use a MIDI track routed to the unit's port.

Notes on the protocol

  • Roland addresses are four 7-bit bytes, so counting carries at 128, not 256. Part 1 is 11 00 00 00 and Part 16 is 14 60 00 00.
  • Some values are sent as nibbles, 2 or 4 bytes carrying 4 bits each: wave numbers, delay times, master tune and all MFX and reverb parameters.
  • The MC-909 leaves out a 4-byte value that straddles a 128-byte boundary when answering a bulk request. The editor therefore asks for those values on their own: tone 4's wave L in a rhythm pad, and the last parameter of each MFX.
  • Individual edits go out as DT1 messages (command 12). Host automation uses Quick SysEx, model ID 5D.

Glossary

Part
One of the 16 channels of the MC-909, each holding a patch or a rhythm kit.
Tone
One of four sound layers inside a patch.
TMT
Tone Mix Table: how the four tones are combined and which keys and velocities play each.
TVF / TVA
Time-variant filter and amplifier: the filter and volume sections, each with its own envelope.
FXM
Frequency cross modulation, a per-tone effect that mixes wave tones for metallic sounds.
MFX
Multi-effects, two of them, applied to parts that you route through them.
SysEx
System exclusive MIDI: the manufacturer-specific messages used to read and set parameters.
DT1 / RQ1
Roland's "data set" and "data request" commands.
